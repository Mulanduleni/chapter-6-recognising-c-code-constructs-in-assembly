# Chapter 6 — Recognising C Code Constructs in Assembly

![Reverse Engineering](https://img.shields.io/badge/Reverse%20Engineering-Assembly-blue)
![IDA Pro](https://img.shields.io/badge/Tool-IDA%20Pro-red)
![Language](https://img.shields.io/badge/Language-C-green)
![Compiler](https://img.shields.io/badge/Compiler-Dev--C++-orange)

Practical reverse engineering exercises focused on recognising common C programming constructs in assembly language using Dev-C++ and IDA Pro.

---

## Tools Used

* Dev-C++
* GCC Compiler (included with Dev-C++)
* IDA Free / IDA Pro
* Windows 10 Virtual Machine

---

## Dev-C++ Download

Dev-C++ was used for writing, compiling, and running the C programs used throughout this practical manual.

Official Download:

https://www.embarcadero.com/free-tools/dev-cpp

---

## Topics Covered

* Global and local variables
* Arithmetic operations
* If statements
* Nested if statements
* Loops
* While loops
* Function call conventions
* Switch statements
* Arrays
* Graph analysis in IDA Pro
