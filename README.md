
# Chapter 6 — Recognising C Code Constructs in Assembly

This repository contains practical reverse engineering exercises focused on recognising common C programming constructs in assembly language using Dev-C++ and IDA Pro.

The exercises cover:

* Global and local variables
* Arithmetic operations
* If statements
* Nested if statements
* Loops
* Function call conventions
* Switch statements
* Arrays
* Graph analysis in IDA Pro

## Tools Used

* Dev-C++
* GCC Compiler
* IDA Free / IDA Pro
* Windows 10 Virtual Machine

## Educational Purpose

This repository was created for educational and learning purposes to assist students studying:

* Reverse Engineering
* Malware Analysis
* Assembly Language
* Software Security
* Low-Level Programming
